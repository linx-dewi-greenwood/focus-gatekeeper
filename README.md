# 一事一毕 · 注意力助手

守住当前这一件事：切换应用或网页时问一句“这一步属于当前这条线吗？”，
突发情况登记为岔路并按四象限决定先后，处理完带你回到主线。

```
Focus\
├─ extension\   浏览器扩展（Chrome / Edge），v0.3.0
├─ hub\         中控（Electron 桌面程序），v0.2.0
└─ README.md
```

- **中控**常驻在托盘，是唯一的“大脑”：主线、岔路、四象限、计时都只在中控里，**只有一个时钟**。
  它读取 Windows 的前台窗口，所以切到 Word、微信、PDF 阅读器等任何应用都能管到。
- **浏览器扩展**只负责浏览器：检测网站切换并上报中控、按中控的指令在网页里弹卡片和切换标签页。
  扩展通过 `ws://127.0.0.1:47321` 连接中控；**中控没开时，扩展会自动把它启动起来**（原生消息，见下）。
  Chrome 和 Edge 可以同时装、同时连，看到的是同一条主线。
- 判断规则写在 `extension\engine.js`，中控引用这一份。

## 安装

### 1. 浏览器扩展

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），打开右上角 **开发者模式**
2. 点 **加载已解压的扩展程序**，选择仓库里的 **`extension`** 文件夹（不是仓库根目录）
3. 已经打开的网页刷新一次

扩展的 ID 固定为 `jkoppfcpiceehbfcbloeggopnieekhoo`（由 `manifest.json` 里的 `key` 决定，Chrome 和 Edge 里一样）。

### 2. 中控（需要 Node.js）

1. 安装 Node.js LTS：<https://nodejs.org/>（装好后在终端里运行 `node -v` 能看到版本号）
2. 打开“命令提示符”，运行：

```bat
cd hub
npm install
npm start
```

`npm install` 会下载 Electron（约 100 MB），只需要一次。如果下载很慢，先运行
`set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 再 `npm install`。

启动后会打开控制面板，右下角任务栏托盘里有图标。关掉面板窗口中控仍在运行；退出请在托盘图标右键 → 退出中控。
托盘菜单里可以勾选“开机自动启动”。

### 3. 让扩展能自动启动中控（自动完成）

**手动启动过一次中控就行。** 中控每次启动都会向 Chrome / Edge 登记一个“原生消息主机”（`hub\native-host.bat`），
只写当前用户的注册表（`HKCU\Software\Google\Chrome\NativeMessagingHosts\com.focus_gatekeeper.hub` 和 Edge 对应的位置），不需要管理员权限。
之后浏览器启动、你点扩展弹窗里的“启动中控”、或者做事做到一半中控被关掉时，扩展都会把中控在后台拉起来。

如果移动了 Focus 文件夹，再手动启动一次中控，登记会自动更新。

## 怎么用

1. 打开你要工作的应用（比如 Word），再从托盘打开控制面板：写下**一件事**、选时间盒和提醒档位，
   在“这件事会用到的应用”里勾上需要的应用（刚才在用的应用会自动加入），点“开始这一件事”。
   也可以在浏览器扩展的弹窗里开始，效果一样。
2. 屏幕右下角出现倒计时角标。
3. 切到不属于这件事的**应用**时，中控弹出提问卡；在浏览器里打开不属于这件事的**网站**时，网页里弹出提问卡：
   - **属于，继续**：放行，以后在这条线里不再问
   - **这是突发情况**：登记岔路（四象限 + 需要多久 + 断点备注）
   - **记到稍后**：存进稍后清单并切回去
   - **返回**：切回原来的应用 / 页面
4. 被打断时按 **Alt+B**（任何应用里都可以），或点角标上的“被打断”。断网时会自动问要不要开“修网络”岔路。
5. 岔路完成或超时，会切回原来的应用或标签页，并显示断点备注。

中控的卡片窗口只和卡片一样大，不会盖满屏幕。诊断日志在 `%APPDATA%\focus-hub\hub.log`（托盘 → 打开日志），只记进程名，不记窗口标题。

**卡片关不掉 / 屏幕被挡住时：** 按 `Esc` 关闭当前卡片（提问卡上 `Esc` 等于“返回”）；或按 **Alt+Shift+B** 强制关闭中控的卡片；
或托盘图标右键 →“关闭当前卡片”。

不会提问的情况：在同一个应用里换窗口、切到桌面/资源管理器/开始菜单/任务管理器、停留不到 0.7 秒的切换。

## 规则

| 象限 | 登记时 | 主线时间到、岔路还没结束 |
| --- | --- | --- |
| 重要且紧急 | 立即开始 | 置换为新主线，原主线挂起（**2 小时内最多一次**；额度用完按“紧急不重要”处理） |
| 紧急不重要 | 立即开始 | 继续岔路，做完回主线收尾，主线不变 |
| 重要不紧急 | 默认搁置（可选“现在就做”） | 以主线为准，收尾时提醒被搁置的岔路 |
| 不紧急不重要 | 默认存入稍后清单（可选“现在就做”） | 以主线为准 |

| 档位 | 不属于当前线时 | 岔路超时 |
| --- | --- | --- |
| 0 观察 | 不提示，只记录 | 不提示 |
| 1 轻提示 | 角落卡片，3 秒后消失（鼠标悬停不消失） | 角落卡片 |
| 2 坚定 | 弹出卡片（网页里全屏，桌面应用时在屏幕中间），必须选一项 | 弹出卡片 |
| 3 严格 | 默认返回；放行需输入“我确定现在要看”并等 30 秒 | 自动搁置并切回 |

### 收尾小结：每次切换分四类

| 类别 | 怎么来的 |
| --- | --- |
| 必要切换 | 点了“属于，继续”；或当时没回答、停留不到 2 分钟（预判） |
| 突发情况 | 登记成了岔路 |
| 拦下的分心 | 点了“返回”或“记到稍后”——你自己发现并回来了 |
| 分心 | 当时没回答、停留超过 2 分钟（预判） |

“当时没回答”指 0 观察档（只记录不提问）和 1 轻提示档卡片自动消失。小结里会把这些切换列出来，可以一键改成“必要”或“分心”；
改成“必要”时可以选择“记住”，下次做**同名的事**时自动放行这个应用/网站。记住的放行可以在面板的“记住的放行”里删除。

各类岔路预置了放行的应用和网站，例如“消息”放行微信、QQ、Teams、Outlook；“报错”放行 VS Code、终端、Stack Overflow、GitHub；
“网络”放行系统设置、路由器后台（192.168.x.x）和测速网站。

## 隐私

- 所有数据只在本机：中控的状态文件在 `%APPDATA%\focus-hub\state.json`，扩展的在浏览器本地存储。
- 窗口标题只用来在卡片上显示，不保存；记录里只有进程名（如 `winword`）和网站域名。
- 中控的 WebSocket 只监听本机，并拒绝普通网页的连接（只接受浏览器扩展）。

## 测试

```bat
cd hub
npm test
```

用模拟的前台窗口事件和模拟的浏览器扩展测试中控核心（不需要打开 Electron）。

## 文件

| 文件 | 作用 |
| --- | --- |
| `extension\engine.js` | 规则引擎：主线、岔路栈、四象限、置换额度、计时（由中控运行；扩展只用其中的判断函数） |
| `extension\background.js` | 浏览器适配器：标签页切换检测、连接中控、中控没开时自动启动它 |
| `extension\content.js` | 卡片和角标界面（网页里用；中控的卡片窗口和角标窗口也直接用它） |
| `extension\popup.*` | 扩展弹窗（中控的控制面板也直接用它） |
| `hub\src\main.js` | 中控主进程：窗口、托盘、Alt+B、断网检测、登记自动启动 |
| `hub\src\native-host.js`、`launcher.js`、`hub\native-host.bat` | 让浏览器扩展能启动中控（原生消息） |
| `hub\src\core.js` | 中控核心：状态文件、计时、应用切换判断、与扩展通信 |
| `hub\src\watcher.js`、`fgwatch.ps1` | 前台窗口检测（PowerShell 内嵌 C#，调用 Win32 `GetForegroundWindow`） |
| `hub\ui\*` | 中控窗口页面；`shim.js` 让扩展的界面代码在中控里运行 |
| `hub\test\core.test.js` | 中控核心测试 |

## 已知限制

- 前台窗口检测只支持 Windows。
- 扩展离不开中控：中控没法启动时（比如还没手动启动过一次），扩展只提示，不会自己计时。
- UWP 应用（如“设置”、“照片”）显示为同一个进程，暂时分不开。
- 全屏游戏或演示时，置顶卡片可能被盖住。
- 部分杀毒软件可能拦截 PowerShell 里的窗口切换调用；被拦时提问照常，只是“返回”不会自动切回应用。
